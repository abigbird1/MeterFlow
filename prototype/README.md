# MeterFlow 交互原型（纯前端）

对应《[requirements.md](../requirements.md) v1.0》的可交互页面原型。**只做交互设计演示，无任何服务端逻辑**，全部数据为内存模拟数据（刷新即重置）。

## 打开方式

直接双击打开 `index.html` 即可（无需构建、无外部依赖、可离线运行）。

- Chrome / Edge 打开：`prototype/index.html`
- 演示基准时间固定为 **2026-11-03 10:00（UTC+8）**

## 原型结构

```
prototype/
├── index.html        入口
├── css/styles.css    设计系统（纯 CSS，无外部依赖）
└── js/
    ├── data.js       模拟数据 + 计费模拟引擎（阶梯计价 / 抵扣链 / 停服判定）
    ├── utils.js      工具库（弹窗 / Toast / 步骤条 / CSV 导出 / 权限）
    ├── tenant.js     租户控制台（11 个功能模块）
    ├── admin.js      管理后台（11 个功能模块，六岗位权限）
    └── app.js        登录 / 双端切换 / 角色切换 / 路由
```

## 已知简化

- 所有支付为前端模拟（无真实网关）；订单倒计时为真实 15 分钟，可通过「模拟超时」按钮加速演示；
- 模拟上报的抵扣链为演示级换算（赠送/内置按指标原生单位扣减，资源包按当前单价折算金额）；
- 刷新页面即恢复初始演示数据。
